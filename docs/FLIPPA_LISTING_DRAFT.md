## Suggested title

Mobile-first Couples Engagement Web App with Real-time Two-Player Games, XP and Private Rooms

## Short summary

Yarper is a mobile-first two-player couples engagement web app. It lets two people join a private shared space, play prompt-based mini-games, exchange answers and reactions, and build shared progress through XP, levels, daily quests and streaks.

## Features

- Private two-player rooms with six-character invite codes.
- Five prompt categories: questions, challenges, truth-or-dare, cards and date-night ideas.
- Synchronized gameplay, answers and emoji reactions.
- XP, levels, daily quests and streak rewards.
- Mini-game utilities and a timed challenge.
- Mobile-responsive single-page frontend.
- Supabase PostgreSQL backend and Deno Edge Function.
- Vercel-hosted production deployment.
- 30-day idle session expiry, server-side revocation and proof-of-possession session recovery.
- Authenticated whole-room deletion from Settings.
- Scheduled cleanup of rate-limit metadata.
- Complete set of 15 applied database migration files included in the repository.
